# 🚀 WinOptiKit (v3.15)

**WinOptiKit** is a modern, lightweight, open-source Windows optimization and diagnostic toolkit built with PowerShell and WPF (Modern Dark Mode). Designed for gamers and general users to safely clean, optimize, and repair Windows.

---

## ✨ Features

- 🎮 **Gaming & Anti-Stuttering Optimizations:** Enable HAGS, CPU priority tuning, and Game Mode.
- 🧹 **Deep Cache Cleaner:** Flushes DirectX Shader Cache, temporary files, and system junk across all drives.
- 🛠️ **System Diagnostics & Repair:** Native one-click launch for `SFC /scannow` and `DISM RestoreHealth`.
- 🌐 **Network & DNS Utilities:** Flush DNS cache and reset TCP/IP stack instantly.
- 📦 **Bloatware Remover:** Easily scan and uninstall preinstalled Windows apps.
- ⚡ **Startup Manager:** Inspect and clean unwanted applications running at boot.

---

## 💻 How to Run

1. Download or clone the repository.
2. Right-click `WinOptiKit_GUI_EN.ps1` (or your launcher script).
3. Select **Run with PowerShell** as Administrator.
